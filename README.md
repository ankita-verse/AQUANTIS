AquaSense: Smart Water Quality Prediction Using Explainable Machine Learning

1. Introduction

Water is one of the most essential natural resources required for the survival of living organisms. The quality of water plays a significant role in maintaining human health, environmental balance and public hygiene. However, water from different sources may contain varying amounts of dissolved substances, minerals and chemical compounds that can affect its quality.

Traditional water quality assessment generally involves collecting water samples and conducting laboratory tests to examine different physical and chemical parameters. Although these methods are important, analysing multiple parameters can require time, specialised equipment and technical expertise.

With the advancement of Machine Learning, data-driven techniques can be used to analyse water quality data and identify patterns that may help in predicting the potability class of water samples.

AquaSense is a Machine Learning based project developed to predict whether a water sample is labelled as potable or non-potable based on its measured water quality parameters. The system uses a publicly available Water Potability dataset obtained from Kaggle. It considers nine input parameters, including pH, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic Carbon, Trihalomethanes and Turbidity.

The project implements and compares three Machine Learning algorithms: Logistic Regression, Decision Tree Classifier and Random Forest Classifier. Their performances are evaluated using different classification metrics such as Accuracy, Precision, Recall and F1-score.

To make the system easier to interact with, a web-based application is developed using Streamlit. It allows users to enter water quality parameter values and receive a prediction generated by the selected trained model.

This project demonstrates how Machine Learning can be applied to a real-world classification problem and how predictive models can be integrated into a simple interactive application.

2. Problem Statement

Water quality assessment involves analysing several physical and chemical characteristics of a water sample. Understanding the relationship between these parameters and the potability classification can be challenging when dealing with large datasets.

The main problem addressed in this project is to develop a Machine Learning based classification system that can analyse multiple water quality parameters and predict whether a given water sample belongs to the potable or non-potable class based on patterns learned from historical data.

The system aims to compare different classification algorithms, evaluate their predictive performance and provide an interactive interface for obtaining predictions.

The project focuses on exploring the application of Machine Learning in water quality classification rather than replacing laboratory-based water testing methods.

3. Objectives

The major objectives of the AquaSense project are:

1. Dataset Collection: To obtain a publicly available water quality dataset containing different physical and chemical parameters along with their corresponding potability labels.

2. Data Preprocessing: To examine the dataset, identify missing values and handle them using suitable preprocessing techniques such as median imputation.

3. Exploratory Data Analysis: To analyse the distribution of water quality parameters, study the target variable and understand possible relationships among different features through graphical visualisations.

4. Model Implementation: To implement three supervised Machine Learning classification algorithms: Logistic Regression, Decision Tree Classifier and Random Forest Classifier.

5. Model Evaluation: To evaluate the implemented models using Accuracy, Precision, Recall and F1-score.

6. Performance Comparison: To compare the results of all three algorithms and identify the model that performs best according to the selected evaluation metrics.

7. Interactive Application Development: To develop a user-friendly web application using Streamlit that accepts water quality parameters and displays the model's prediction.

8. Practical Learning: To understand the complete Machine Learning workflow, from dataset collection and preprocessing to model training, evaluation and application development.

4. Dataset Description

The dataset used in this project is the Water Potability Dataset, obtained from Kaggle.

Dataset Source: https://www.kaggle.com/datasets/adityakadiwal/water-potability

The dataset contains 3,276 water samples, with nine input features and one target variable named "Potability".

Each row represents a water sample, while each column represents a particular water quality parameter or its corresponding potability label.

4.1 Features of the Dataset

The dataset consists of the following nine input features:

Feature| Description
pH| Indicates the acidic or basic nature of water.
Hardness| Represents the concentration of dissolved minerals, mainly calcium and magnesium.
Solids| Represents the total dissolved solids present in water.
Chloramines| Indicates the amount of chloramines present in water.
Sulfate| Represents the concentration of sulfate ions.
Conductivity| Measures the ability of water to conduct electricity.
Organic Carbon| Represents the amount of organic carbon present in water.
Trihalomethanes| Represents the concentration of trihalomethanes in water.
Turbidity| Indicates the cloudiness of water due to suspended particles.

4.2 Target Variable

The target variable is "Potability".

It contains two possible classes:

- 0: Water sample labelled as non-potable in the dataset.
- 1: Water sample labelled as potable in the dataset.

The target variable is used by the Machine Learning algorithms to learn patterns and classify water samples.

4.3 Dataset Information

- Total number of records: 3,276
- Number of input features: 9
- Number of target variables: 1
- Total number of columns: 10
- Type of problem: Supervised Machine Learning
- Learning task: Binary Classification

5. Data Preprocessing

Data preprocessing is an important step in Machine Learning because raw datasets may contain missing values, inconsistent information or other issues that can affect model performance.

Before training the classification models, the Water Potability dataset was examined and prepared using the following preprocessing techniques.

5.1 Handling Missing Values

During dataset inspection, missing values were identified in three features:

- pH: 491 missing values
- Sulfate: 781 missing values
- Trihalomethanes: 162 missing values

The missing values were handled using Median Imputation with the "SimpleImputer" class from Scikit-learn.

Median imputation replaces missing entries with the median value of the corresponding feature. It was selected because the median is less affected by extreme values compared to the mean.

The imputer was fitted using the training data and then applied to the test data to avoid data leakage.

5.2 Feature and Target Separation

The dataset was divided into two parts:

- Input Features (X): The nine water quality parameters.
- Target Variable (y): The Potability column.

The input features were used to train the models, while the target variable provided the corresponding class labels.

5.3 Train-Test Split

The dataset was divided into training and testing sets using the "train_test_split()" function from Scikit-learn.

- Training data: 80%
- Testing data: 20%
- Random state: 42
- Stratification: Enabled

The training dataset was used to train the classification models, while the testing dataset was used to evaluate their performance on unseen samples.

5.4 Feature Scaling

Feature scaling was applied to the Logistic Regression model using "StandardScaler".

This technique standardises numerical features so that they have a comparable scale. It helps prevent features with larger numerical values from dominating the learning process.

Feature scaling was not applied to the Decision Tree and Random Forest models because tree-based algorithms do not generally require standardisation.

6. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to understand the structure, distribution and characteristics of the dataset before applying Machine Learning algorithms.

Python libraries such as Pandas, Matplotlib and Seaborn were used for data analysis and visualisation.

The following analyses were performed:

6.1 Missing Values Analysis

The missing values in each feature were examined to identify incomplete records and determine the appropriate preprocessing technique.

The analysis showed that pH, Sulfate and Trihalomethanes contained missing values, whereas the remaining features and target variable had no missing entries.

6.2 Potability Distribution

The target variable was analysed to understand the distribution of potable and non-potable samples.

The dataset contains:

- Non-potable samples (0): 1,998
- Potable samples (1): 1,278

Approximately 61% of the samples are labelled non-potable and 39% are labelled potable.

This indicates a moderate imbalance between the two classes, which makes it important to consider multiple evaluation metrics rather than relying only on accuracy.

6.3 Feature Distribution Analysis

Histograms were generated to examine the distribution of individual water quality parameters.

These visualisations helped in understanding the variation and spread of different features across the dataset.

6.4 Correlation Analysis

A correlation heatmap was generated to examine the relationships among the numerical features and the target variable.

It provides a visual representation of how strongly different variables are linearly related to one another.

6.5 Statistical Summary

Descriptive statistical analysis was performed to obtain information such as mean, median, standard deviation, minimum and maximum values of the numerical features.

This helped in understanding the overall characteristics and variation of the dataset.

7. Machine Learning Algorithms

Three supervised Machine Learning classification algorithms were implemented in this project to predict the potability class of water samples.

The algorithms were selected to compare different approaches to binary classification.

7.1 Logistic Regression

Logistic Regression is a supervised Machine Learning algorithm commonly used for classification problems.

It estimates the probability of a sample belonging to a particular class and assigns the sample to a class based on the predicted probability.

In this project, Logistic Regression was implemented using Scikit-learn. Median imputation and feature scaling were applied before classification.

7.2 Decision Tree Classifier

Decision Tree is a supervised Machine Learning algorithm that makes predictions using a tree-like structure of decision rules.

It divides the dataset into smaller groups based on feature values. Each internal node represents a decision based on a feature, while the leaf nodes represent the predicted class.

Decision Trees are relatively easy to understand and interpret compared to many other classification algorithms.

7.3 Random Forest Classifier

Random Forest is an ensemble learning algorithm that combines multiple Decision Trees to improve prediction performance.

Each tree produces a prediction, and the final classification is determined through majority voting.

It can capture complex relationships in the dataset and generally provides better stability than a single Decision Tree.

8. Experimental Results and Model Evaluation

After preprocessing, all three classification algorithms were trained using the training dataset and evaluated using the testing dataset.

The following evaluation metrics were used:

- Accuracy: Measures the overall proportion of correctly classified samples.
- Precision: Measures how many samples predicted as potable were actually potable according to the dataset labels.
- Recall: Measures how many actual potable samples were correctly identified.
- F1-score: Represents the harmonic mean of Precision and Recall.

8.1 Model Comparison

The following table presents the experimental results obtained from the implemented models.

Algorithm| Accuracy| Precision| Recall| F1-score
Logistic Regression| 0.6098| 0.0000| 0.0000| 0.0000
Decision Tree| 0.5960| 0.4813| 0.4531| 0.4668
Random Forest| 0.6668| 0.6484| 0.3232| 0.4323

8.2 Result Analysis

The experimental results show differences in the performance of the three classification algorithms.

- Logistic Regression achieved an accuracy of approximately 60.98%, but it failed to correctly identify any potable samples in the test set, resulting in zero precision, recall and F1-score for the positive class.
- Decision Tree achieved an accuracy of approximately 59.60% and an F1-score of approximately 0.4668.
- Random Forest achieved the highest accuracy of approximately 66.68% and the highest precision of approximately 0.6484. However, its recall was lower than that of the Decision Tree model.

8.3 Selected Model

Based on the experimental comparison, the Decision Tree Classifier was selected as the model for the AquaSense application because it achieved the highest F1-score among the three implemented algorithms.

It also achieved a higher recall than Random Forest, making it the preferred model under the selected F1-score-based comparison.

The trained Decision Tree pipeline was saved using the Joblib library and integrated into the Streamlit application for generating predictions.

9. Application Development

To make the trained Machine Learning model accessible through a simple user interface, a web application was developed using Streamlit.

Streamlit is a Python framework that allows developers to create interactive web applications for Machine Learning and data science projects.

9.1 Application Features

The AquaSense application provides the following features:

- A simple and interactive user interface.
- Nine numerical input fields corresponding to the water quality parameters.
- Integration with the trained Decision Tree classification pipeline.
- A prediction button to generate the classification result.
- Display of the predicted class as either POTABLE or NON-POTABLE.
- An educational disclaimer explaining the limitations of the prediction.

9.2 Working of the Application

The application follows these steps:

1. The user opens the AquaSense web application.
2. The user enters values for the nine water quality parameters.
3. After clicking the prediction button, the entered values are organised into a Pandas DataFrame.
4. The trained Decision Tree pipeline is loaded using Joblib.
5. The input data is passed to the trained model.
6. The model generates a prediction.
7. The application displays the predicted class on the webpage.

10. Project Limitations

Although AquaSense demonstrates the application of Machine Learning in water quality classification, it has certain limitations:

- The model's predictions depend on the quality and characteristics of the training dataset.
- The dataset contains missing values that require preprocessing.
- The classification performance is moderate and can be improved through further experimentation.
- The model has been trained using a specific publicly available dataset and may not generalise well to all real-world water samples.
- The application does not perform actual laboratory testing or measure water quality directly.

Important Disclaimer: AquaSense is an educational Machine Learning project. Its predictions are not certified assessments of drinking-water safety and must not be used as a substitute for laboratory water-quality testing.

12. Installation and Execution Instructions

Follow the steps below to run the AquaSense project on a local computer.

Step 1: Install Python

Install Python 3 or a compatible version on your computer.

Step 2: Download the Project

Clone or download the AquaSense project repository from GitHub.

Step 3: Download the Dataset

Download the Water Potability dataset from Kaggle:

https://www.kaggle.com/datasets/adityakadiwal/water-potability

Extract the downloaded file and place the CSV file inside the "dataset" folder.

Step 4: Install Required Libraries

Open the terminal in the project folder and install the required Python libraries:

pip install pandas numpy matplotlib seaborn scikit-learn streamlit joblib

Step 5: Check the Dataset

Run the following command:

python check_dataset.py

Step 6: Perform Exploratory Data Analysis

Run:

python eda.py

The generated graphs and statistical summary will be stored in the "results" folder.

Step 7: Train the Machine Learning Models

Run:

python model_training.py

This will train the three classification algorithms, evaluate their performance and save the model comparison results.

The selected Decision Tree model will also be saved in the "results" folder.

Step 8: Run the Web Application

Run the following command:

python -m streamlit run app.py

The AquaSense application will open in a web browser, allowing users to enter water quality parameters and obtain a model prediction.

13. Conclusion

The AquaSense project demonstrates the application of supervised Machine Learning techniques to a water quality classification problem.

A publicly available Water Potability dataset was analysed and preprocessed to prepare it for model development. Three classification algorithms, namely Logistic Regression, Decision Tree Classifier and Random Forest Classifier, were implemented and evaluated.

The experimental results showed that the Random Forest model achieved the highest accuracy, whereas the Decision Tree model achieved the highest F1-score among the three algorithms. Based on the F1-score comparison, the Decision Tree model was selected and integrated into the Streamlit application.

The project also demonstrates how a trained Machine Learning model can be connected to an interactive web interface to make predictions accessible to users.

Overall, AquaSense provided practical experience in dataset handling, data preprocessing, exploratory data analysis, model training, performance evaluation and application development.
