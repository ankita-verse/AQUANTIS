🌊 AQUANTIS

Intelligent Water Quality Analysis

Machine Learning-Based Water Quality Prediction

1. Introduction

AQUANTIS is a machine learning-based project designed to explore water quality data and predict water potability labels using machine learning algorithms.

The application provides an interactive interface where users can enter water quality parameters and receive a prediction generated by a trained Support Vector Machine (SVM) model.

It also provides data visualisations, statistical insights and comparisons of different machine learning algorithms.

2. Problem Statement

Water quality assessment involves analysing several physical and chemical parameters. Understanding the relationship between these parameters can be challenging when dealing with large datasets.

AQUANTIS explores how machine learning techniques can be applied to historical water quality data to identify patterns and predict dataset potability labels.

3. Project Objectives

- Analyse water quality data using Python.
- Perform data preprocessing and exploratory data analysis.
- Implement multiple machine learning algorithms.
- Compare model performance using evaluation metrics.
- Develop an interactive web application for predictions.
- Present analytical results through visualisations.

4. Dataset Information

Dataset: Water Potability Dataset
Source: Kaggle
Records: 3,276
Input Features: 9
Target Variable: Potability

Dataset link: https://www.kaggle.com/datasets/adityakadiwal/water-potability

Input Features

1. pH
2. Hardness
3. Solids
4. Chloramines
5. Sulfate
6. Conductivity
7. Organic Carbon
8. Trihalomethanes
9. Turbidity

The target variable, Potability, contains two classes:

- 0: Non-potable dataset label
- 1: Potable dataset label

5. Data Preprocessing

The dataset was examined for missing values and prepared before model training.

The preprocessing steps included:

- Identifying missing values.
- Handling missing numerical values using median imputation.
- Applying feature scaling where appropriate.
- Preparing training and testing data.

6. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to understand the dataset and identify patterns.

The following visualisations were generated:

- Missing Values Analysis
- Potability Distribution
- Feature Distributions
- Correlation Heatmap
- Statistical Summary

7. Machine Learning Algorithms

Four machine learning algorithms were implemented:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Support Vector Machine (SVM)

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score

8. Model Performance

The following results were obtained during model evaluation:

Model                 | Accuracy   | Precision   | Recall   | F1-score
Logistic Regression   | 60.98%     | 0.00%       | 0.00%    | 0.00%
KNN                   | 61.43%     | 50.93%      | 32.03%   | 39.33%
Decision Tree         | 59.60%     | 48.13%      | 45.31%   | 46.68%
SVM                   | 67.07%     | 70.41%      | 26.95%   | 38.98%

Key Observations

- SVM achieved the highest accuracy and precision.
- Decision Tree achieved the highest recall and F1-score.
- Logistic Regression did not identify positive samples in this evaluation.
- SVM was selected as the primary model for the application based on its accuracy.

12. Installation and Execution

Step 1: Clone the repository

git clone https://github.com/ankita-verse/AquaSense.git

Step 2: Navigate to the project directory

cd AquaSense

Step 3: Install the required dependencies

pip install -r requirements.txt

Step 4: Run the application

python -m streamlit run app.py

The AQUANTIS application will open in your web browser.

13. Limitations

- Predictions depend on patterns learned from the available dataset.
- Model performance varies across evaluation metrics.
- The SVM model has relatively low recall.
- The application does not perform real-time laboratory testing.

Important: AQUANTIS is an educational machine learning project. Its predictions must not be treated as a certified assessment of drinking-water safety.
